# Spec: i18n รองรับ 2 ภาษา (ไทย/อังกฤษ) — Phase 8 (batch 1)

> วันที่: 2026-08-07 · สถานะ: อนุมัติ design แล้ว รอ review spec
> แนวทาง: **B** — CI4 Language files (ฝั่ง PHP) + JS i18n module (ฝั่ง React islands)

## 1. เป้าหมายและขอบเขต

**เป้าหมาย:** วางระบบ i18n ให้ทั้งแอป (CI4 เรนเดอร์ HTML + React islands) รองรับ **ไทย/อังกฤษ** แล้วแปล "หน้าหลัก" ให้ครบ 2 ภาษาก่อน (batch 1) ส่วนที่เหลือทยอยเติมเฟสถัดไปโดยไม่ต้องวางระบบใหม่

**นอกขอบเขต (batch 2+ — เฟสถัดไป):** การแปลข้อความใน islands ที่มีข้อความเยอะ (RequestsManager, MembersManager, CarsManager, MasterData, ActivityLog, Timeline, MyRequests, DriverJobs, BookingForm, NotificationBell ฯลฯ) — โครงพร้อมแล้ว เพียงเพิ่ม key + แทน string ทีหลัง

**หลักการ:** ไทยเป็นภาษาหลัก (default) และเป็น fallback เสมอ — ทุก key ต้องมีค่าไทยครบ ถ้าค่าอังกฤษหายให้ตกกลับเป็นไทย (ไม่โชว์ key ดิบ)

## 2. การไหลของภาษา (locale flow)

- **Cookie `lang`** — แหล่งความจริงของภาษาปัจจุบัน ค่า `th` | `en` อายุ ~1 ปี path `/` · ตั้ง/อ่านฝั่ง server เท่านั้น (JS ไม่อ่าน cookie ตรงๆ แต่รับ locale จาก `<meta name="locale">` ที่ PHP ฝังให้) → ตั้ง `HttpOnly` ได้เพื่อความปลอดภัย
- **`app/Filters/LocaleFilter.php`** (global `before`) — อ่าน cookie `lang`; ถ้าไม่มี/ไม่อยู่ใน `['th','en']` ใช้ `'th'` → เรียก `service('request')->setLocale($lang)` · ลงทะเบียนใน `Config/Filters.php` (`$globals['before']`)
- **`app/Config/App.php`** — `$defaultLocale = 'th'` · `$supportedLocales = ['th', 'en']` · `$negotiateLocale = false` (ไม่เดาจาก Accept-Language — คุมด้วย cookie เท่านั้น)
- **Route สลับภาษา** — `GET /lang/(:segment)` → `Controllers\LocaleController::set($lang)`:
  - validate `$lang ∈ ['th','en']` (ไม่งั้น default `th`)
  - `set cookie('lang', $lang, 1 ปี)`
  - redirect กลับหน้าเดิม (`previous_url()` ถ้าไม่มีใช้ `/`) — ปลอดภัยเฉพาะ path ภายใน (กัน open-redirect: ยอมเฉพาะ URL ที่ขึ้นต้นด้วย base_url)
  - นิยาม route **นอก** filter auth (guest เข้าถึงได้)
- **Meta tag** — ฝัง `<meta name="locale" content="<?= esc(service('request')->getLocale()) ?>">` ใน `templates/shell.php` (ในบล็อก `<head>`) และในหน้า auth (`login.php`, `register.php`) เพื่อให้ islands อ่าน locale ปัจจุบันได้

## 3. ฝั่ง PHP — CI4 Language files

โครงไฟล์ (แยกตามโดเมน ให้ key สั้น อ่านง่าย):

```
app/Language/th/Nav.php       app/Language/en/Nav.php       # เมนู sidebar (ทุก role)
app/Language/th/Common.php    app/Language/en/Common.php    # ปุ่ม/คำทั่วไป (บันทึก ยกเลิก ค้นหา แก้ไข ลบ อนุมัติ ปฏิเสธ …)
app/Language/th/Auth.php      app/Language/en/Auth.php      # login/register (ป้าย ปุ่ม hint ข้อความ)
app/Language/th/Page.php      app/Language/en/Page.php      # pageTitle/subtitle ทุกหน้า
app/Language/th/Dashboard.php app/Language/en/Dashboard.php # การ์ดสรุป/แถบเตือน/panel (สำหรับ props ที่ PHP ส่งให้ island ถ้ามี)
```

- แต่ละไฟล์ return array เช่น `Nav.php`: `['dashboard' => 'แดชบอร์ด', 'calendar' => 'ปฏิทินการจองรถ', 'users' => 'จัดการผู้ใช้งาน', 'bookings' => 'จัดการการจองรถ', 'cars' => 'จัดการรถ', 'myRequests' => 'คำขอของฉัน', 'log' => 'ประวัติการใช้งาน', 'myJobs' => 'งานของฉัน', 'dept' => 'แผนก', 'position' => 'ตำแหน่ง', 'logout' => 'ออกจากระบบ']`
- ใช้ `lang('Nav.dashboard')` แทนข้อความไทย hardcode ใน views/controllers
- **pageTitle/subtitle** ใน controllers → เปลี่ยนจาก string ไทยตรงๆ เป็น `lang('Page.dashboard')` ฯลฯ

## 4. ฝั่ง React islands — JS i18n module

`resources/js/lib/i18n.js`:

```js
import th from '../locales/th.json';
import en from '../locales/en.json';

const dict = { th, en };
// อ่าน locale จาก meta ที่ PHP ฝังให้ (default th)
const locale = document.querySelector('meta[name="locale"]')?.content || 'th';

// t('common.save') -> คำแปลของ locale ปัจจุบัน · fallback: ไทย -> คืน key ดิบ
export const t = (key) => dict[locale]?.[key] ?? dict.th?.[key] ?? key;
export const currentLocale = () => locale;
```

- ไฟล์คำแปล: `resources/js/locales/th.json`, `resources/js/locales/en.json` (key แบน dot-notation)
- ตัวอย่าง `th.json`: `{ "common.save": "บันทึก", "common.cancel": "ยกเลิก", "common.search": "ค้นหา", "dashboard.pendingBookings": "คำขอรอดำเนินการ", ... }`
- แต่ละ island: `import { t } from '../lib/i18n'` แล้วแทน `'บันทึก'` → `t('common.save')`
- Vite bundle JSON เข้ากับ island อัตโนมัติ (ไม่ต้องเพิ่ม entry)
- **batch 1:** ใช้ `t()` จริงใน **Dashboard.jsx** เท่านั้น · islands อื่นค่อยแปลงเฟสถัดไป

## 5. ตัวสลับภาษา (UI)

- **คอมโพเนนต์ PHP** ใน `templates/header.php` — แสดง `TH | EN` (2 ปุ่ม/ลิงก์) ลิงก์ไป `site_url('lang/th')` และ `site_url('lang/en')` · ตัวที่ตรงกับ locale ปัจจุบัน = highlight (สี teal/หนา)
- ใส่ตัวสลับเดียวกันในหน้า **login.php** + **register.php** (มุมบนขวา) — guest สลับได้ก่อนล็อกอิน
- ดีไซน์: กลุ่มปุ่มเล็ก (pill) โทนเดียวกับระบบ (teal active / เทา inactive)

## 6. Validation ฝั่ง server (CI4)

- ข้อความ validation ที่ตั้งเองใน controllers (โดยเฉพาะ `RegisterController`) — batch 1 ย้ายข้อความไปใช้ `lang('Auth.xxx')` หรือไฟล์ `Language/{th,en}/Validation.php` (เฉพาะ custom messages ของ register) เพื่อให้ error เปลี่ยนภาษาตาม locale
- validation ฝั่ง client ใน `register.php` (ข้อความเตือนสีแดง) — อ่านจาก lang ที่ PHP ฝังลง (inline ผ่าน `lang()` ตอนเรนเดอร์ หรือ data-attr) ให้เปลี่ยนภาษาตาม locale

## 7. ขอบเขตแปลรอบแรก (batch 1) — สรุปไฟล์ที่แตะ

**สร้างใหม่:**
- `app/Config/App.php` (แก้ config locale)
- `app/Filters/LocaleFilter.php` + ลงทะเบียนใน `Config/Filters.php`
- `app/Controllers/LocaleController.php` + route ใน `Config/Routes.php`
- `app/Language/{th,en}/{Nav,Common,Auth,Page,Dashboard}.php`
- `resources/js/lib/i18n.js` + `resources/js/locales/{th,en}.json`
- คอมโพเนนต์ตัวสลับภาษา (partial PHP)

**แก้ให้ใช้ lang/t:**
- `templates/sidebar.php` (เมนูทุก role → `lang('Nav.*')`)
- `templates/header.php` (โปรไฟล์ dropdown + ใส่ตัวสลับภาษา)
- `templates/shell.php` (meta locale)
- controllers ที่ตั้ง pageTitle/subtitle (Dashboard, Member, Request, User\Page, Driver\Page ฯลฯ → `lang('Page.*')`)
- `auth/login.php`, `auth/register.php` (ข้อความ + ตัวสลับ + validation client)
- `RegisterController.php` (validation messages → lang)
- `islands/Dashboard.jsx` (แทน string → `t()`)

## 8. เกณฑ์ทดสอบ (acceptance)

1. กด EN → เมนู sidebar, header, pageTitle/subtitle, หน้า login/register, Dashboard เปลี่ยนเป็นอังกฤษครบ · กด TH → กลับเป็นไทย
2. Cookie จำภาษา: รีเฟรช/ปิด-เปิดเบราว์เซอร์แล้วยังเป็นภาษาที่เลือก
3. Guest ที่หน้า login สลับภาษาได้ (ยังไม่ล็อกอิน) แล้วหน้า login เปลี่ยนภาษา
4. ลบ key อังกฤษบางตัวออก → หน้านั้นตกกลับเป็นไทย (ไม่โชว์ key ดิบ ไม่พัง)
5. islands อื่นที่ยังไม่แปล (batch 2) ยังแสดงไทยตามปกติ ไม่พัง
6. `php spark routes` โหลด route `/lang/{lang}` ได้ · `npm run build` ผ่าน
